# Game Brief: 读海

**One-sentence pitch:** 你驾着一艘船，读着海面上的风向和海流修正航向，在补给耗尽前登上那片因此才现身的新海岸。

## Core loop

- 看清海面上的风和流
- 用手指改航向，让船穿过去
- 风流一变就再修正
- 登上海岸，这片陆地按地理显形；错过海岸或补给耗尽，这一趟结束

## Player goal & fail state — what "working" looks like

靠读懂风、流和岸线，在补给耗尽前抵达这一趟的历史海岸。被风流带过海岸，或补给归零仍看不见陆地，这一趟失败。

## MVP — what must exist to be the game

1. 一艘船，用触摸改变航向
2. 看得见、并且会推动船的风和海流
3. 一条能够抵达、也能够错过的海岸
4. 补给耗尽就结束这一趟
5. 登陆后揭示一片历史海岸
6. 登陆时给出一句地理原因，说明这片岸为何在这里
7. 从出发到登陆或失败的完整一局

## Out of scope — not building this

- 第二片大陆和更多历史航线（以后只更换风、流、岸线的数据）
- 贸易、港口、舰队、战斗、多人
- 长文阅读和书摘列表
- 存档、养成，以及这一趟之外的进度
- 只能靠悬停完成的操作

## Build order

1. 船能航行，手指能改变航向
2. 风和流看得见，并真正推动船
3. 海岸能抵达，也能错过
4. 补给计时，耗尽即失败
5. 登陆揭示这一片海岸，并给出一句地理原因
6. 收成从出发到登陆或失败的一局

**Who it's for / what they feel:** 想在几分钟里感到「是我读懂了这片海，才找到陆地」的人。

**Art & audio direction:** 扁平海图，墨线海岸，色带表示海流，箭头表示风，一艘小船；风声与水声，登陆时一个短音。

**Reference game:** 《大航海时代》——这一版只留一艘船沿风和海流驶向未知海岸；没有港口、贸易和舰队。
